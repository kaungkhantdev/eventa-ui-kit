Get started — connecting CSS & JS

Eventa is static HTML with no build step. Two shared files make every component work: assets/app.css supplies all the component classes & color tokens, and assets/shell.js injects the sidebar and wires the interactive components. Copy the head, put your markup in a <main>, include the scripts — done.

What each shared file does

config.js

Tailwind config — darkMode:'class' + the semantic color tokens. Load right after the Tailwind CDN.

app.css

Every component class — .btn, .card, .input, .badge, .data-table, .panel … plus the token variables.

shell.js

Renders the double sidebar & wires the declarative modals, tabs and accordions. Include once at the end of <body>.

settings-ui.js

Optional — wires [data-toggle] switches and [data-reveal] password fields on settings pages.

Interactive components work through data-* attributes that the shared scripts pick up automatically — you never write component JS. Add the trigger, add the target, done.

Empty states

.empty inside a .card. Two flavours, same block. First run — the workspace has no data yet, so the copy explains what will fill the page and offers the one real next step. No results — data exists but a filter matched nothing, so the action is to clear the filter, never to create something — it adds .empty-sm for the tighter padding a table cell needs, and its data-clear-filters button is wired globally in shell.js (it resets the page's search boxes, filter selects and pill tabs, then re-fires input/change). A page ships both its real content (marked data-when-data) and its first-run block (data-empty hidden); shell.js swaps them when the URL carries ?empty=1 — try events.html?empty=1.

Area line chart

A dependency-free trend chart — a hand-built SVG with Catmull-Rom smoothing, gridlines, a gradient area fill and a ringed last point. It reads the dark class, so it repaints on theme flip.

Donut chart

Percentage donut from stacked SVG arcs (radius 15.915 so the dash length equals the percentage), with a centered total overlay and a legend.

Bar meters

Labeled progress-bar rows for a chart-library-free horizontal bar chart — a truncating label, a flex-1 track and a right-aligned value.

QR code

A white, hair-bordered frame wrapping an aspect-square code — the white background is forced so it stays scannable in dark mode.
