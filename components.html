Design system

Components

Every building block in the Eventa kit — buttons, badges, inputs, cards, tables and overlays — shown live in light & dark with copy-paste markup. All components are plain classes from assets/app.css; no build step, no framework.

Tailwind + semantic tokens Light & dark Copy-paste HTML

Colors

Semantic tokens are CSS variables that flip between light & dark automatically — use them (bg-surface, text-muted) instead of literal grays so new UI is dark-mode-ready. The brand green is a fixed hex.

Brand & accents

Typography

The face is Inter on a compact ~13px base. Figures use tnum (tabular) so numbers line up in tables and stats.

Icons

Hugeicons stroke-rounded font. Drop in <i class="hgi-stroke hgi-name">, size with text-[Npx], color with currentColor.

Buttons

Base class .btn + a variant. Add .btn-sm for the compact size or .btn-icon for square icon buttons.

Panels & modals

Fully declarative — a trigger [data-open="id"] opens the .panel or .modal with that id; the overlay, [data-close] or Esc closes it. Click a trigger to try it.
